# EasyTaskMgr 1.0.0-beta.2

> Minecraft **26.3** · Fabric · Java **25**

本次更新带来**中英双语支持**，并补上了一批定时提醒与界面细节。

---

## 新增

- **自动语言识别**：默认跟随 Minecraft 语言设置——**只有简体中文使用中文**，
  其他任何语言（含未翻译语言）一律回退英文。
- **语言配置开关**：设置界面（`K`）里可在「自动 / 简体中文 / English」之间切换，
  改完立即生效，也会写进 `config/easytaskmgr.json` 的 `language` 字段。
- **全量双语覆盖**：HUD、四个界面、聊天提示、方向词、成就条件都支持中英。
- **物品 / 成就名跟模组语言走**：直接读取原版语言文件，英文模式下不会再出现中文候选词。
- **新增「每次上线时提醒」**：与原来「上线提醒一次」并列；前者每次进服都提醒、不自动完成。
- **新增游戏内时间提醒**：
  - 预设「白天 06:00」「黑夜 19:00」两个按钮；
  - 也可以自定义「每 N 个游戏日的 HH:MM」，到点提醒一次。
- **间隔提醒补充说明**：输入框旁提示「至少 1 分钟」。
- **待办列表改为单页滚动**：去掉分页，滚轮上下滚动，右侧有滚动条，顶部显示 `1-4 / 共 12 条`。

## 修复

- 英文模式下候选列表仍显示中文物品名 / 成就名。
- 定时提醒的模式按钮显示成 `timer.on_join`。
- 英文标签较长导致设置页按钮文字被截断、语言按钮与 HUD 预览框重叠。
- 完成提示里 `✓` 重复显示。

## 移除

- **合成任务**：触发条件（从合成格取走成品）不符合实际使用习惯，整项功能已移除；
  旧任务文件里的 `CRAFT` 类型会自动转成普通任务，不会报错。

## 兼容性

- 需要 **Fabric Loader ≥ 0.20.1** 与 **Fabric API 0.165.0+26.3**。
- 任务与配置文件向下兼容；旧配置没有 `language` 字段时按 `auto` 处理；
  旧的 `ON_JOIN` 任务语义不变（提醒一次后自动完成）。
- 服务端可选安装：安装后才能获得完整成就候选列表与队友待办共享。

## 安装

1. 安装对应 26.3 的 Fabric Loader；
2. 把 **Fabric API** 和 `easytaskmgr-1.0.0-beta.2.jar` 放进 `.minecraft/mods`；
3. 启动游戏，右上角出现待办面板即安装成功。

## 已知问题

- 游戏时间提醒按世界时钟（0 tick = 06:00）判断，若整合包改过时间流速（如更长的昼夜），
  预设时间会随实际昼夜比例偏移；
- 切换语言后成就目录会重新拉取，约有 1 秒空窗；服务端未装模组时回退本地已同步的数据。
