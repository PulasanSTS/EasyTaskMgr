# EasyTaskMgr 1.0.0-beta.1

> Minecraft **26.3** · Fabric · Java **25**

在游戏里记不住要做的事？按一下快捷键记下来，右上角一直挂着；收集够了、成就到手、走到地方、到点了，它会主动提醒你。

这是 EasyTaskMgr 的首个公开测试版。

---

## 亮点

- **一处记录，全程可见**：`B` 快速添加，右上角 HUD 常驻，位置可以直接拖
- **五类条件自动检测**：收集物品、合成物品、完成成就、前往坐标、时间提醒
- **中文名搜索**：输入「钻石」「来硬的」就能选，不用背 id；候选支持滚轮翻页
- **坐标导航**：HUD 显示方向箭头、剩余距离、相对方向和当前速度
- **联机共享**：队友的待办会出现在你的 HUD 上（可开关）
- **HUD 交互模式**：按 `V` 释放鼠标，直接点 HUD 上的普通任务即可完成

| 项目 | 版本 |
| --- | --- |

## 安装

1. 安装对应 26.3 的 Fabric Loader；
2. 把 **Fabric API** 和 `easytaskmgr-1.0.0-beta.1.jar` 放进 `.minecraft/mods`；
3. 启动游戏，右上角出现「待办清单」即安装成功。

> 多人服务器：客户端装即可用大部分功能；**服务端也装**时，成就候选列表和队友待办共享才是完整的。

## 功能一览

### 待办

- 快捷键 `B` 弹出输入框：内容 + 优先级（低 / 普通 / 高 / 紧急），回车即添加
- 列表界面（`N`）：勾选完成、编辑、删除、翻页、清空已完成
- 长文字自动换行，不再截断成省略号

### 条件触发

| 类型 | 完成条件 |
| --- | --- |
| 收集物品 | 背包内达到指定数量，可选择把**打开过的容器 / 末影箱 / 背包里的潜影盒**也算进去 |
| 合成物品 | 从创建任务起累计合成数量（普通合成与 shift 快速合成都计数） |
| 完成成就 | 指定成就达成 |
| 前往坐标 | 走到目标半径内，HUD 实时显示方向箭头 / 距离 / 速度 |
| 时间提醒 | 上线提醒一次，或每隔 N 分钟提醒 |

- 完成时：聊天栏提示 + 提示音 + HUD 顶部闪一下
- 定时提醒统一显示为 `任务提醒：<内容>`
- 任务可附加一句提醒，完成后**单独一行**显示：`完成「XXX」任务的附加提醒：YYY`

### HUD 与设置

- 位置用屏幕百分比锚定，换分辨率不跑偏；设置里可直接**拖动预览框**定位
- 可调：面板宽度、最多显示条数、是否显示背景 / 距离 / 速度 / 方向箭头 / 队友 / 音效
- `H` 临时隐藏 HUD

### 联机

- 勾选「共享」的待办会同步给同服队友，显示在 HUD 的「队友」区域
- 服务端只做轻量中转（缓存 + 转发），不需要数据库；玩家退出时自动清理

### 快捷键

| 按键 | 功能 |
| --- | --- |
| `B` | 快速添加待办 |
| `N` | 打开待办列表 |
| `K` | 打开设置 |
| `H` | 隐藏 / 显示 HUD |
| `V` | HUD 交互模式（点击完成任务，再按退出） |

## 本版主要修复

- **候选列表点了没反应**：26.3 鼠标左键的 `button()` 返回 1 而非 0，修正判定逻辑
- **成就候选不全 / 混进配方**：26.3 服务端只同步「有进度」的成就，改为向服务端请求全量目录（过滤 `recipes/` 与技术成就）
- **成就名显示英文**：服务端只发翻译键与物品 id，客户端按本地语言解析
- **HUD 拖不动 / 调宽度没反应**：修正命中判定，面板宽度改为跟随设置
- **编辑界面文字与输入框重叠**：重排为固定分区 + 按类型显示字段
- **坐标任务 z 输入框盖住半径框**：重算控件宽度
- **shift 合成不计数**：在 `quickMoveStack` 结果槽处补计数，并按 tick 去重
- **定时 / 附加提醒文案**：统一格式，附加提醒单独成行

## 已知问题
