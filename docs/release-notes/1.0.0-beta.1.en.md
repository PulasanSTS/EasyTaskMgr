# EasyTaskMgr 1.0.0-beta.1

> Minecraft **26.3** · Fabric · Java **25**

Never lose track of what you meant to do in-game. Press a key to note it down, keep it in the top-right HUD, and get pinged when you have collected enough, earned the advancement, reached the spot, or the timer is up.

This is the first public beta of EasyTaskMgr.

---

## Highlights

- **Write once, see always**: `B` to quick-add, a persistent HUD in the top-right corner you can drag anywhere
- **Five condition types**: collect items, craft items, finish advancements, reach coordinates, timed reminders
- **Search by localized name**: type "diamond" or an advancement title instead of memorizing ids, with a scrollable suggestion list
- **Coordinate guidance**: the HUD shows a direction arrow, remaining distance, relative bearing and current speed
- **Multiplayer sharing**: teammates' todos show up on your HUD (toggleable)
- **HUD interaction mode**: press `V` to release the mouse and click a plain task on the HUD to complete it

## Installation

1. Install Fabric Loader for 26.3;
2. Drop **Fabric API** and `easytaskmgr-1.0.0-beta.1.jar` into `.minecraft/mods`;
3. Launch the game — a "待办清单 / Todo" panel appears in the top-right corner.

> Multiplayer: the client mod covers most features; installing it on the **server** too enables the full advancement catalog and teammate todo sharing.

## Features

### Todos

- `B` opens a quick-add box: text + priority (low / normal / high / urgent), Enter to add
- Task list (`N`): complete, edit, delete, paginate, clear completed
- Long text wraps instead of being cut off with an ellipsis

### Condition triggers

| Type | Completes when |
| --- | --- |
| Collect items | Inventory reaches the target count; optionally also counts **opened containers / ender chests / shulker boxes in your inventory** |
| Craft items | Cumulative crafts since creation (normal and shift-click crafting both count) |
| Advancement | The target advancement is earned |
| Coordinates | You come within the target radius; HUD shows arrow / distance / speed |
| Timed reminder | Once when you join, or every N minutes |

- On completion: chat message + sound + a short flash on the HUD
- Timed reminders are shown as `任务提醒：<text>` (Task reminder: …)
- Tasks can carry an extra note, printed on its own line: `完成「XXX」任务的附加提醒：YYY`

### HUD & settings

- Anchored by screen percentage, so it stays put across resolutions; drag the preview box in settings to reposition
- Configurable: panel width, max lines, background, distance / speed / direction arrow / teammates / sound
- `H` temporarily hides the HUD

### Multiplayer

- Shared tasks are relayed by the server to other players and listed under "队友" (teammates) on the HUD
- The server only caches and forwards — no database required; entries are cleared when a player leaves

### Key bindings

| Key | Action |
| --- | --- |
| `B` | Quick-add a task |
| `N` | Open the task list |
| `K` | Open settings |
| `H` | Hide / show the HUD |
| `V` | HUD interaction mode (click to complete, press again to exit) |

## Notable fixes in this build

- **Suggestion clicks did nothing**: in 26.3 the left mouse button reports `button() == 1`, not 0
- **Incomplete advancement list / recipes mixed in**: the 26.3 server only syncs advancements that have progress; the mod now requests the full catalog (filtering `recipes/` and technical entries)
- **Advancement names in English**: the server now sends translation keys and item ids; the client localizes them
- **HUD could not be dragged / width did nothing**: fixed hit detection, panel width now follows the setting
- **Overlapping labels in the editor**: reworked into fixed sections with type-dependent fields
- **Coordinate z field covered the radius field**: recalculated control widths
- **Shift-crafting was not counted**: counting moved to the result slot in `quickMoveStack`, deduplicated per tick
- **Reminder wording**: unified format, extra reminder printed on its own line

## Known issues

- The advancement "prerequisites" UI is temporarily disabled (parser and protocol kept; re-enable with the `advancementRequirements` config)
- On a vanilla server with only the client mod, the advancement catalog is limited to locally synced entries
- Container counting keeps the maximum seen per container type, it does not distinguish individual chests
- Shift-craft counting uses a new hook — please report any missed crafts
