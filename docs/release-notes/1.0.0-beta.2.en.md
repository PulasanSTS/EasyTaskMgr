# EasyTaskMgr 1.0.0-beta.2

> Minecraft **26.3** · Fabric · Java **25**

This release adds **English support**, plus a batch of timer and UI refinements.

---

## Added

- **Automatic language detection**: follows Minecraft's language by default.
  **Only Simplified Chinese (`zh_cn`) uses Chinese**; every other language falls back to English.
- **Language option**: switch between Auto / 简体中文 / English in the settings screen (`K`).
  Applies immediately and is stored as `language` in `config/easytaskmgr.json`.
- **Full two-language coverage**: HUD, all four screens, chat messages, direction words and advancement conditions.
- **Item / advancement names follow the mod language**: vanilla language files are read directly,
  so English mode no longer shows Chinese suggestions.
- **New "every time I join" reminder**: alongside the existing one-shot join reminder;
  the new mode fires on every join and does not auto-complete.
- **New in-game time reminders**:
  - presets for **Day 06:00** and **Night 19:00**;
  - or a custom **HH:MM every N game days**.
- **Interval hint**: the editor now shows "(min 1)" next to the interval field.
- **Task list is now a single scrolling page**: pagination is gone; scroll with the wheel, with a scrollbar
  on the right and a `1-4 of 12` indicator at the top.

## Fixed

- Suggestion lists still showed Chinese item / advancement names in English mode.
- The timer mode button rendered as `timer.on_join`.
- Longer English labels clipped the settings buttons and overlapped the HUD preview.
- Duplicated `✓` in the completion message.

## Removed

- **Craft tasks**: the trigger (taking the result out of the crafting grid) did not match real usage,
  so the whole feature is gone. Existing `CRAFT` tasks are converted to normal tasks on load.

## Compatibility

- Requires **Fabric Loader ≥ 0.20.1** and **Fabric API 0.165.0+26.3**.
- Existing tasks and configs keep working; a config without `language` is treated as `auto`;
  existing `ON_JOIN` tasks keep their old semantics (remind once, then complete).
- Server installation is optional: it enables the full advancement catalog and teammate todo sharing.

## Installation

1. Install Fabric Loader for 26.3;
2. Drop **Fabric API** and `easytaskmgr-1.0.0-beta.2.jar` into `.minecraft/mods`;
3. Launch the game — the todo panel appears in the top-right corner.

## Known issues

- In-game time reminders use the world clock (0 tick = 06:00); modpacks that change day length
  will shift the presets accordingly;
- Switching language re-requests the advancement catalog (about a second); on a server without the mod
  it falls back to locally synced data.
